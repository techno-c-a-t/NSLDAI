# 🛠️ Руководство администратора NSLDAI (Phantom)

Краткое руководство по управлению, настройке и командам администрирования бота Фантом.

---

## 🔐 1. Авторизация и безопасность

Команды управления доступны **строго администратору** при совпадении любого из условий:
1. `from_user.id == MY_USER_ID` (неизменяемый числовой ID в Telegram, дефолт `37329040`).
2. `from_user.username.lower() == MY_USERNAME.lower()` (регистронезависимо, дефолт `techno_c_a_t`).
3. `from_user.is_self == True` (отправка команд напрямую от лица аккаунта юзербота).

Попытки вызова админ-команд посторонними пользователями отклоняются роутером с записью в лог: `🔒 [ROUTER] Обработчик пропущен (требуются права админа is_me=False)`.

## 📋 2. Справочник команд администратора

### 🌐 Управление доступом чатов
| Команда | Описание |
|---|---|
| `Фантом, разреши этот чат` | Добавляет текущий чат в БД `chats_master` (`is_active = 1`) и активирует его в памяти. |
| `Фантом, список чатов` | Выводит список всех зарегистрированных чатов с их ID, названиями и статусом активности. |
| `Фантом, запрети этот чат` | Деактивирует текущий чат в БД (`is_active = 0`) и исключает из белого списка. |
| `Фантом, запрети чат [id]` | Деактивирует чат по указанному числовому ID. |

### 🔄 Синхронизация истории
* **При перезапуске бота** в разрешенные групповые чаты отправляется запрос:  
  `Снова в сети. Nikitos, читать историю?`
* **Управление:**
  * `да` / `давай` / `yes` — запуск загрузки пропущенных сообщений (до `2000` сообщений, отсечка по `checkpoint_max_id`).
  * `нет` / `отмена` / `пропусти` — пропуск синхронизации, фиксация истории с текущего момента.
* **ЛС (личные сообщения):** никогда не блокируются синхронизацией, подгружаются бесшумно до 100 сообщений.

### 🔇 Режимы тишины и голосовых сообщений
| Команда | Описание |
|---|---|
| `Фантом, включи чистый режим` | Переводит чат в режим реакций: вместо текстовых сервисных сообщений бот ставит Telegram-реакции (`👀` — в обработке, `😭` — ошибка, тишина при аудио без речи). |
| `Фантом, выключи чистый режим` | Возвращает стандартные текстовые сообщения («Расшифровываю...», «Вникаю...»). |
| `Фантом, авто гс` | Включает автоматическую расшифровку всех входящих ГС и аудио в чате. |
| `Фантом, гс по запросу` | Отключает авто-расшифровку. ГС обрабатываются только по реплаю на них. |

### 📊 Лимиты и квоты ИИ
| Команда | Описание |
|---|---|
| `Фантом, включи лимиты` | Активирует суточный лимит бесплатных запросов для пользователей без личного API-ключа в текущем чате (`quota_mode = 1`). |
| `Фантом, выключи лимиты` | Снимает суточные ограничения для всех участников чата (`quota_mode = 0`). |
| `Фантом, лимит запросов [число]` | Задает суточный лимит запросов на одного пользователя (по умолчанию 5). |

### 💬 Диалоги в личных сообщениях (ЛС)
| Команда | Описание |
|---|---|
| `Фантом, включи лс` | Глобально разрешает диалоги с пользователями в личных сообщениях юзербота. |
| `Фантом, выключи лс` | Отключает реакцию на диалоги в ЛС (кроме администратора). |

### 📡 Трассировка и логирование в ЛС
| Команда | Описание |
|---|---|
| `Фантом, трассировка в лс вкл` | Включает отправку сырых JSON-логов запросов и промптов админу в ЛС. |
| `Фантом, трассировка в лс выкл` | Отключает стриминг трассировки в ЛС. |

### 🗄️ База данных и обслуживание
| Команда | Описание |
|---|---|
| `Фантом, дамп` | Выгружает последние 20 сообщений текущего чата в чат. |
| `Фантом, дамп > 20` | Выгружает полную историю текущего чата в файл `dump.txt`. |
| `Фантом, очисти историю` / `вайп` | Полностью очищает таблицу истории текущего чата в SQLite. |
| `Фантом, лимит сводки [число]` | Устанавливает дефолтное число сообщений для команды `!сводка` (по умолчанию 100). |

### 👤 Досье участников
* `Досье @username: [текст]` — ручное добавление/обновление досье участника в БД SQLite.
* `Фантом, досье гемма вкл` / `выкл` — переключение автоматического извлечения фактов о пользователях нейросетью.

## ⚙️ 3. Лимиты и конфигурация (`.env`)

```ini
# Идентификаторы администратора
MY_USERNAME=techno_c_a_t
MY_USER_ID=37329040

# База данных и история
DB_NAME=database.db
MAX_SAVED_HISTORY=20000       # Лимит ротации истории в SQLite на чат
SYNC_HISTORY_LIMIT=2000      # Максимум сообщений при синхронизации

# AI провайдеры и модели
BASE_PROXIED_URL=https://gemini-proxy.nikn1q2w.workers.dev/v1beta/openai
DEFAULT_API_KEY=AIzaSy...     # Мастер-ключ Gemini
USER_API_KEYS_JSON={"username": "AIzaSy..."} # Личные ключи участников
```

## 🎙️ 4. Пайплайн голосовых сообщений (Архитектура)

1. **Очередь SberSpeech:** Строго последовательная (FIFO). Бот занимает слот прямо под ГС сообщением со статусом.
2. **Эстимейт ожидания:** 5с на короткое ГС (до 3 мин) и 10с на длинное (>3 мин).
3. **Интерактивный таймер:**
   * Топ очереди и активная расшифровка: обновляются **посекундно (1с)**.
   * Хвост очереди (позиции >= 2): обновляются **раз в 5 секунд** для защиты от Telegram `FLOOD_WAIT`.
4. **Сжатие транскрипций (>30 слов):** Асинхронно в фоне через 3 круга:  
   `gemma-4-31b-it` ⇄ `gemma-4-26b-a4b-it` ➔ `GigaChat`.  
   Сырой текст Сбера выводится сразу и **никогда не пропадает**.
